# Cairn

Decision layer for early-stage VCs and the founders they back: links market news to holdings, open decisions and meetings, and keeps investor questions and founder answers in one record.

- `index.html` — desktop prototype (v91)
- `mobile.html` — mobile view
- `v37.html` — earlier version, kept for comparison

Demo only. Holdings, funds, people and meetings are assumed or fictional; company facts come from public sources. AI drafting and voice input work only inside claude.ai; on GitHub Pages they fall back to manual entry.
